# 生成问答对 Prompt

请根据以下文本内容生成{questions_per_group}个问答对。

## 要求

1. 问题必须基于文本内容，可以准确回答
2. 每个问题应该有不同的侧重点，覆盖文本的不同方面
3. 答案应该准确、完整，引用文本中的具体信息
4. 对于每个问题，需要明确指出答案来源于哪些文本块（chunk_index）

## 文本内容

```
{context}
```

## 输出格式

请严格按照以下JSON格式输出（不要包含任何其他文字）：

```json
[
    {{
        "question": "问题1",
        "answer": "答案1",
        "chunk_index_list": [0, 1, 2]
    }},
    {{
        "question": "问题2",
        "answer": "答案2",
        "chunk_index_list": [3, 4]
    }}
]
```
